## 1. Project Overview
With the widespread adoption of Generative Large Language Models (LLMs) such as GPT-4, Llama, and Mistral, the ability to automatically verify whether a given text in Spanish was authored by a human or generated by an artificial intelligence has become critical for academic integrity, journalistic authenticity, and content moderation.

This project develops an end-to-end NLP solution to detect synthetic vs human-authored Spanish texts. Starting from a lightweight lexical baseline in Phase 1, progressing to a fine-tuned Transformer in Phase 2, and concluding with a deployed interactive application in Phase 3.

## 3. Phase 1 (Baseline Models) Summary

### Selected Metric: Macro F1-Score
- **Primary Metric:** **Macro F1-Score**. F1 balances Precision and Recall, ensuring equal penalization for false positives (falsely accusing a human author) and false negatives (failing to identify AI generation).
- **Secondary Metrics:** Accuracy, Precision, Recall, and Inference Latency per sample.

### Text Representation Justification
- **Baseline Representation:** **TF-IDF with unigrams and bigrams (`ngram_range=(1,2)`)**. AI models frequently exhibit stereotypical transition markers (*"en consecuencia"*, *"asimismo"*, *"por consiguiente"*) and predictable lexical distributions. TF-IDF captures these n-gram patterns in microseconds without GPU requirements.
- **Advanced Representation (Phases 2 & 3):** Contextual subword tokenization and Transformer embeddings to capture deep semantic dependencies and discourse structure.

### Baseline Comparison on Test Set (90 Samples)
| Model | Approach | Macro F1 | Accuracy | Precision | Recall | Training Time | Inference Latency |
|---|---|---|---|---|---|---|---|
| **Base Model (TF-IDF + Logistic Regression)** | Supervised (from scratch) | **0.9667** | **96.67%** | **0.9669** | **0.9667** | 0.038 s | **0.07 ms / sample** |
| **Pretrained Model (Zero-Shot / Perplexity)** | Pretrained (no fine-tuning) | **0.6848** | **71.11%** | **0.8169** | **0.7111** | N/A | **0.08 ms / sample** |

#### Key Takeaway & Next Steps:
The baseline model achieves strong discriminative performance on characteristic vocabulary markers with minimal compute overhead. The off-the-shelf pretrained language model displays inherent zero-shot understanding but lacks domain calibration. In **Phase 2 (November 12)**, we will fine-tune a Spanish Transformer (BETO / RoBERTa-BNE) to achieve robust semantic generalization.

## 4. Setup & Quickstart

### Prerequisites
- Python 3.10, 3.11, or 3.12
- Git

### Installation
```bash

git clone https://github.com/ElElimios/cepesin_chuy.git
cd cepesin_chuy

# Install dependencies
pip install -r requirements.txt
```

### Reproducing Baseline Results
To run the technical report notebook:
```bash
jupyter notebook notebooks/entrenamiento.ipynb
```
All outputs, metrics, and visualization figures are pre-rendered and fully reproducible.
