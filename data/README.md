# Dataset: Human or Machine? (Spanish Corpus)

## Description
This dataset is curated specifically for **RNAP Hack 2026 - Challenge 1: Human or Machine?**. It addresses the task of binary text classification in Spanish: distinguishing between human-written texts (`label: 0`) and machine-generated texts (`label: 1`, generated by modern generative models such as GPT-3.5/GPT-4/Llama).

## Dataset Statistics
- **Total samples**: 600 balanced examples (300 Human, 300 Machine/AI).
- **Language**: Spanish (`es`).
- **Splits**:
  - `train.csv`: 420 samples (70%, 210 Human, 210 AI)
  - `val.csv`: 90 samples (15%, 45 Human, 45 AI)
  - `test.csv`: 90 samples (15%, 45 Human, 45 AI)
- **Stratification**: All splits are strictly stratified by the target label (`stratify=y`, `random_state=42`) to prevent class imbalance or data leakage.

## Schema
| Column | Type | Description |
|---|---|---|
| `id` | Integer | Unique identifier for each sample |
| `text` | String | Text content in Spanish |
| `domain` | String | Domain / topic tag (science, history, literature, tech, etc.) |
| `label` | Integer | Target class: `0` = Human, `1` = Machine / AI |
| `label_name` | String | Textual label: `"Humano"` or `"Máquina"` |
| `word_count` | Integer | Number of words in the text |

## Linguistic Characteristics & Stylistic Differences
- **Human Texts (`label: 0`)**: Exhibit natural stylistic variability, diverse sentence pacing, subjective / personal anecdotes, colloquial connectors, and idiomatic expressions.
- **Machine Texts (`label: 1`)**: Display high syntactic symmetry, standard formal transition markers (*"en conclusión"*, *"es importante destacar"*, *"asimismo"*, *"por consiguiente"*), consistent sentence lengths, and structured academic phrasing.
